# Frontend Projects Collection 🚀

A collection of modern, responsive frontend applications built with React and cutting-edge web technologies. This repository serves as a portfolio of frontend engineering projects showcasing expertise in user interface design, state management, performance optimization, and responsive web development.

## 📚 Projects Included

### 1. **Meals App** 🍽️
A feature-rich recipe discovery application built with React + Vite.
- Browse and search for recipes from around the world
- Detailed recipe information with ingredients and instructions
- Category browsing and filtering
- Responsive design for all devices

**Tech Stack**: React.js, Vite, Fetch API, CSS3 Animations

[View Detailed Documentation](./mealsapp/README.md)

## 📦 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- Git

### General Setup
```bash
# Clone repository
git clone https://github.com/meenbajwa/frontend.git
cd frontend

# Navigate to specific project
cd mealsapp

# Install dependencies
npm install

# Start development server
npm run dev
```
